# Plan 02-02: Content Quality Pre-Validation & Execution Receipts

## Objective

Guarantee that all AI content expanded across WordPress fleet properties passes strict editorial quality gates (heading hierarchy, zero hallucinated placeholder tokens) and generates persistent audit receipts for fleet governance.

## Tasks

<task type="auto">
  <name>Task 1: Implement Content Quality Validator for Heading Hierarchy and Placeholders</name>
  <files>src/katteb/wordpress.py</files>
  <action>
    Implement `validate_generated_content(html: str, target_word_count: int = 1500) -> list[str]` in `src/katteb/wordpress.py`:
    - Check for minimum heading hierarchy: Articles >= 1,000 words must include at least 2 `<h2>` headings and at least 1 `<h3>` heading.
    - Check for hallucinated placeholder tokens or AI leakage:
      - Regex match against `\[(City|Country|Name|Insert|Destination|State|Region|URL|Link|Date|Phone)\]` (case-insensitive).
      - Check for phrases like `"as an ai language model"`, `"i cannot provide"`, `"lorem ipsum"`, `"todo:"`, `"[insert "`
    - If violations are found, return list of error messages; raise `ContentQualityError` in `expand_and_update_post` before calling `wp_update_post`.
  </action>
  <verify>
    Verify with unit test that HTML containing `[City]` or missing H2 tags is rejected with explicit descriptive error messages.
  </verify>
</task>

<task type="auto">
  <name>Task 2: Implement Execution Audit Receipt Generator</name>
  <files>src/katteb/wordpress.py, src/katteb/cli.py</files>
  <action>
    Implement `generate_expansion_receipt(site: str, results: list[dict], output_dir: str = "receipts") -> str` in `src/katteb/wordpress.py`:
    - Generate a clean Markdown summary table containing:
      - Timestamp & target WordPress site
      - List of processed posts: Post ID, Post Title, Previous Word Count, New Word Count, Delta (+X words), Status (Success/Failed)
      - RankMath metadata updated (`rank_math_title`, `rank_math_description`)
      - Pods custom fields updated (`travel_guide`)
      - Any warnings or rejected posts
    - Update `wp_batch_expand` and `wp_expand_post` in `src/katteb/cli.py` to write the receipt to disk (e.g. `expand-receipt-<timestamp>.md`) and print the file location in console output.
  </action>
  <verify>
    Verify that executing batch expansion (or calling the receipt generator with test payloads) outputs a valid markdown file.
  </verify>
</task>
