## Tasks

<task type="auto">
  <name>Task 1: Implement Telemetry Event Logger and Metrics Aggregator</name>
  <files>src/katteb/telemetry.py, src/katteb/config.py, src/katteb/wordpress.py</files>
  <action>
    1. Update `src/katteb/config.py` to allow configuring `telemetry_file` (default `~/.katteb/telemetry.jsonl`) and `credit_alert_threshold` (default 50) via environment variables (`KATTEB_TELEMETRY_FILE`, `KATTEB_CREDIT_ALERT_THRESHOLD`) and config file.
    2. Create `src/katteb/telemetry.py`:
       - `log_telemetry_event(event_type: str, data: dict, log_path: Path | None = None) -> None`: Appends structured JSON lines with ISO 8601 timestamps.
       - `get_telemetry_summary(log_path: Path | None = None) -> dict[str, Any]`: Computes aggregate metrics: total runs, total words generated, total duration, credits charged, success rate, and per-site breakdown.
       - `check_credit_threshold(client: KattebClient, threshold: int | None = None) -> dict[str, Any]`: Queries `client.get_credits()`, compares available credits against threshold, returns status (`OK`, `WARNING`, `CRITICAL`), and builds human/machine alert payload.
    3. Wire telemetry logging into `WordPressFleetManager.expand_and_update_post()` and batch operations, recording execution duration, word count delta, and quality gate results.
  </action>
  <verify>
    Verify with unit tests that `log_telemetry_event` persists events to JSONL and `get_telemetry_summary` computes metrics accurately.
  </verify>
</task>

<task type="auto">
  <name>Task 2: Implement CLI Commands for Threshold Checks and Telemetry</name>
  <files>src/katteb/cli.py</files>
  <action>
    1. Add `katteb account check-threshold` command:
       - Options: `--threshold` (integer, default from config or 50).
       - Logic: Calls `check_credit_threshold()`.
       - Exit codes: 0 if OK, 2 if credits are below threshold (standard alerting exit code for monitoring scripts/Activepieces branches).
       - Output: Supports `--json` or rich colored alert card.
    2. Add `katteb telemetry` command group:
       - `katteb telemetry summary`: Prints aggregate fleet metrics in Rich table or JSON.
       - `katteb telemetry tail`: Displays recent N events.
  </action>
  <verify>
    Run `katteb account check-threshold --help` and `katteb telemetry summary --help`.
  </verify>
</task>
